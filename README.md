🌍Topography Map\
(30DayMapChallenge)\
This repository demonstrates how to create a global topography map using R programming language.

🧰 Tools & Libraries
This project uses the following R packages:
 
library(rnaturalearth)\
library(terra)\
library(sf)\
library(tidyverse)\
library(lwgeom)\
library(extrafont)\
library(ncmeta)\
library(ncdf4)\
library(patchwork)
